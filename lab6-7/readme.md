## Запуск

Из директории проекта в WSL или Linux, с PHP и расширением `pdo_sqlite`:

```bash
SAWM_DEMO_ACCOUNTS=1 php -d display_errors=0 -d log_errors=1 -S 127.0.0.1:8000 router.php
```

Это локальный режим с учебными аккаунтами; не публикуйте его в интернете. Запускайте через `router.php`: он разрешает только известные страницы и CSS, не выдаёт SQLite и внутренние файлы. Журналы по умолчанию лежат в соседней с проектом папке `.sawm-lab67-logs`; расположение можно задать через `SAWM_LOG_DIR` вне публичной директории.

## Результат

- **ЛР6:** отдельный текстовый журнал фиксирует регистрацию, вход и выход, изменение профиля и операции администратора с аккаунтами. В записях — время UTC, событие, результат и внутренние идентификаторы вместо имён. При достижении 256 КиБ текущий файл архивируется; хранится один предыдущий файл.
- **ЛР7:** ошибки и предупреждения пишутся в отдельный журнал с типом и местом сбоя, без исходного текста исключения и данных запроса. При внутреннем сбое сайт возвращает HTTP 500 и статическую страницу со ссылкой на главную. Оба журнала доступны для просмотра только администратору.

## Проверка

На копии SQLite проверены синтаксис PHP, регистрация, вход и выход, ограничения по ролям, работа с профилем и аккаунтами, просмотр и ротация журналов, запись предупреждения PHP и статический ответ HTTP 500 без технических подробностей.

**Нужен скриншот:** раздел журналов администратора с тестовыми записями без конфиденциальных данных.
